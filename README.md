## PolarX-MD
PolarX MD is a WhatsApp Multi-Device bot built on top of the Baileys library.
It is designed to be fast, lightweight, and easy to customize without modifying the core code.
This project is fully open-source — you are free to modify, rebrand, and build your own bot from this codebase at no cost, without requiring any permission.
The command system and overall structure are organized to make customization simple, including bot name, prefix, media assets, and feature extensions.
